# Demonstration recording script — not a completed video

Target length: **2 minutes 50 seconds**. Prerequisite: complete live A–D/E evaluation and listening review after API credit is restored. Do not record offline mocked responses as though they are real analysis. If actual results differ from expectations, show the discrepancy honestly and fix/retest before the final recording.

Prepare the local app, A/B/C WAV files and already-completed live results in separate browser tabs. The recording must show an actual upload and processing. If live latency would exceed the time budget, clearly label an edit that skips waiting; do not invent progress percentages or timings. Include computer audio so the evidence can be heard. Hide terminals, env files, account details and any unrelated windows.

| Time | Screen action | Suggested narration |
| --- | --- | --- |
| 0:00–0:15 | Show upload screen, select A.wav | “Accord turns a short project recording into final commitments, not a meeting summary. This is a synthetic two-speaker conversation.” |
| 0:15–0:40 | Click Find final commitments; show real stages and final result | “The audio is transcribed with speaker segments, then the whole conversation is checked for acceptance, changes and cancellation.” |
| 0:40–1:05 | Open wireframes evidence; play the correction and acceptance | “The wireframe deadline was changed and accepted. October eighth is the final deadline; the earlier date appears only in history.” |
| 1:05–1:25 | Show cancelled announcement and unaccepted dark mode under inactive items | “The cancelled announcement and unapproved suggestion are excluded from active work.” |
| 1:25–1:40 | Show accessibility audit and clarification section | “The audit was agreed, but nobody owns it yet and no deadline was agreed. The app keeps these gaps visible.” |
| 1:40–2:05 | Show B upload/result from a separately recorded live run | “Version B changes one accepted deadline to October ninth. We compare all other states, owners and deadlines to check that they stay the same.” |
| 2:05–2:30 | Show C and its evidence | “Next Friday has no date anchor here, so the wording is preserved without an invented calendar date. Maya declined ownership, so the owner remains unassigned.” |
| 2:30–2:40 | Briefly show D's request for a new recording | “Silence produces no fabricated tasks.” |
| 2:40–2:50 | Show quality report and measured run details | “The repository includes independent expectations, actual outputs and measurements. This small synthetic set is not a universal accuracy claim.” |

If live processing remains blocked, record only an explicitly labelled incomplete-prototype walkthrough and state the API-credit blocker. Such a walkthrough would not satisfy the requested final working demonstration.
