Your audio & privacy

Audio and transcript are processed on this computer by local speech and language models. No paid API is called. Internet access is needed for initial model downloads; the Hugging Face token is only for downloading permitted models.

Original audio stays in this browser. Uploaded audio is held in server memory during processing. Results expire from server memory after 30 minutes or when cleared. Local logs retain timing, model IDs and usage, without audio or transcript. Local electricity and hardware costs are not measured.
